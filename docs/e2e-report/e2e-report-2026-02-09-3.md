## エラー詳細

### 主要な失敗パターン

#### 1. bugs-pane-integration (9件失敗 - 最多)

**エラー**: `docs-tabs` data-testidが見つからない。Bugsタブ切り替え後のUI要素待機でタイムアウト。

```
Bug未選択時の空ペイン表示 Bugsタブに切り替えできる
Bug選択時の3ペイン連動 "before each" hook
BugArtifactEditorドキュメントタブ "before each" hook
BugWorkflowView5フェーズ表示 "before each" hook
タブ切り替え時の選択状態維持 (3件)
UIレイアウト一貫性
フェーズ実行ボタン動作（インフラ確認） "before each" hook
```

**原因**: `docs-tabs` data-testidが見つからず、beforeEach hookで連鎖的に失敗。

#### 2. inspection-workflow (9件失敗)

**エラー**: Inspection関連のUI状態が期待通りにならない。

```
Progress Indicator: needs fix (NOGO result) "before each" hook
NOGO with fix applied "before each" hook
Multi-round inspection "before each" hook
Auto-execution with inspection permission "before each" hook
Executing state indicator "before each" hook
Auto-execution inspection with --autofix "before each" hook
Standalone inspection execution "before each" hook
Inspection fix after NOGO "before each" hook
Auto-execution: NOGO -> autofix -> next inspection round "before each" hook
```

**原因**: Inspection spec.jsonのフェーズ設定でUI描画条件が満たされない。beforeEachでの前提条件設定失敗が連鎖。

#### 3. file-watcher系 (12件失敗: ui-update 5 + root-monitoring 3 + bugs-file-watcher 4)

**エラー**:
```
expect(received).toBe(expected) // Object.is equality
Expected: true
Received: false
```

**原因**: ファイルシステム変更後のUI更新がテスト待機時間（通常10-15秒）内に完了しない。

#### 4. worktree系 (15件失敗: execution 5 + spec-sync 3 + two-stage-watcher 4 + convert 4 + impl-start 3 - 重複除外)

**エラー**:
```
expect(received).toBe(expected) // Object.is equality
Expected: true
Received: false
```

**原因**: Worktree関連UI要素（worktree badge, ImplFlowFrame, convert-to-worktree button）が表示されない。data-testid変更またはレンダリング条件の不一致。

#### 5. auto-execution系 (15件失敗: workflow 2 + permissions 2 + resume 3 + flow 1 + impl-flow 4 + impl-phase 2 + simple 1)

**エラー**:
```
expect(received).toBe(expected) // Object.is equality
Expected: true / Received: false
```

**原因**: 自動実行フローでのエージェント完了検知やUI状態遷移のタイミング問題。一部はbeforeEach hookの前提条件設定失敗による連鎖。

#### 6. agent-resume-log-display (4件全滅)

**エラー**: エージェント再開時のログ保持・追加が動作しない。

```
should preserve previous logs when resuming agent with additional instruction
should add stdin log entry for additional instruction
should add new Session Started log for resumed session
"before each" hook for Multiple resumes accumulate logs
```

**原因**: エージェント再開機能のAPIまたはUI実装の変更。

#### 7. document-review-ui-states (4件失敗)

**エラー**: beforeEach hookで前提条件設定失敗。

```
Status: in_progress (fix_pending) "before each" hook
Status: in_progress (fix_applied, round 2) "before each" hook
Status: approved "before each" hook
Multi-round completed "before each" hook
```

**原因**: spec.jsonの状態設定（electronAPI.updateSpecJson使用）が失敗し、UIが期待状態にならない。
