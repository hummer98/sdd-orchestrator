### W-001: コンポーネント配置場所の明確化

**Issue**: requirements.md (1.3) で「`remote-ui/components/`に配置」と記載されているが、structure.md では共有コンポーネントは `src/shared/components/` に配置すべきとある。Steering違反の可能性。

**Judgment**: **No Fix Needed** ❌

**Evidence**:

structure.mdの規定を再確認すると：

```
### 1. Shared Components (SSOT)
**Location**: `src/shared/components/`
**Content**: Electron版とRemote UI版で共有するUIコンポーネント
```

重要なのは「**Electron版とRemote UI版で共有する**」コンポーネントがshared配置の対象である点。

一方、既存の`remote-ui/components/`には以下のコンポーネントが配置されている：
- `SpecDetailPage.tsx` - Remote UI専用の詳細ページ
- `BugDetailPage.tsx` - Remote UI専用の詳細ページ
- `AgentDetailDrawer.tsx` - Remote UI専用のドロワー
- `AgentsTabView.tsx` - Remote UI専用のタブビュー

これらはすべて**モバイルRemote UI専用**のページ/コンポーネントであり、Electron版では使用されない。

`AgentLogPage`も同様にモバイルRemote UI専用の全画面ページであるため、既存のSpecDetailPage/BugDetailPageと同じ`remote-ui/components/`への配置は**Steering準拠**である。
