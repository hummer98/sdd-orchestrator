## 主要な失敗パターン分析

### 1. `workflow-view` 要素が見つからない (11件)

以下のテストで `[data-testid="workflow-view"]` が5000ms〜10000ms以内に表示されない:
- auto-execution-flow, auto-execution-impl-flow, auto-execution-impl-phase
- auto-execution-intermediate-artifacts, auto-execution-permissions, auto-execution-resume
- auto-execution-workflow, auto-execution-document-review
- document-review-ui-states, inspection-workflow, worktree-execution

**根本原因**: プロジェクト/Spec選択後のUI初期化完了を待機する処理が不十分。`waitForSpecDetailReady()` や `waitForProjectUIReady()` ヘルパーが適用されていない。

### 2. `artifact-editor` 要素が見つからない (2件)

- additional-markdown-files, mermaid-preview

**根本原因**: ArtifactEditorの表示条件（specDetail の markdownFiles ロード完了）を待機していない。

### 3. Worktree関連テストの失敗 (12件)

- worktree-spec-sync (5件), worktree-two-stage-watcher (5件), worktree-execution (2件)

**根本原因**: Worktree内のspec.json/bug.json変更がUI（specStore/bugStore）に反映されるまでの非同期処理の待機が不十分。

### 4. 要素クリック遮断 (2件)

- spec-workflow.e2e.spec.ts: `bg-black/50` オーバーレイがクリックを遮断

**根本原因**: CreateSpecDialogが開いた状態のまま次のテストに進んでいる。前のテストの後処理でダイアログを閉じる必要がある。

### 5. Store API変更 (1件)

- diagnostic.e2e.spec.ts: `setCurrentProject is not a function`

**根本原因**: store APIが変更されたがテストコードが追従していない。
